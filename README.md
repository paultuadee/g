# Little Art Studio

แอประบายสีที่ปรับจากไฟล์ต้นฉบับของคุณ พร้อมถาดสีพาสเทล อุปกรณ์มีมิติ พื้นผิวกระดาษ ลายผ้า ลายไม้ และสีน้ำ

## วิธีใช้

- เปิด `index.html` เพื่อลองหน้าตา หรือเปิดผ่านเว็บเซิร์ฟเวอร์/GitHub Pages เพื่อใช้การเก็บข้อมูลและออฟไลน์อย่างครบถ้วน
- เลือกสีทางซ้าย เลือกพื้นผิวทางขวา พื้นผิวลายจะเลือกเครื่องมือลูกกลิ้งให้อัตโนมัติ จากนั้นแตะพื้นที่ปิดในภาพ
- ปุ่ม More เปิดหน้าพื้นผิวถัดไป ปุ่มดูตัวอย่างเปิดภาพตัวอย่างโดยไม่เปลี่ยนงานที่กำลังวาด
- บนมือถือ เลื่อนแถบสีและพื้นผิวด้านข้างเพื่อดูตัวเลือกทั้งหมด
- กดปุ่มเสียงเพื่อเปิดเอฟเฟกต์และเสียงอังกฤษ ปิดได้ทุกเวลา
- ปุ่มบันทึกเก็บงานในเบราว์เซอร์เครื่องนี้ เปิดเมนูผู้ปกครอง → ผลงานที่บันทึกไว้ → แตะภาพ เพื่อดาวน์โหลด/แชร์ PNG

## เสียงที่รวมอยู่

เอฟเฟกต์แตะและเสียงสำเร็จสร้างด้วย Web Audio ไม่ใช้ไฟล์ภายนอก

เสียงพูดเป็น **ตัวอย่างเสียงสังเคราะห์จากเบราว์เซอร์ ไม่ใช่เสียงเด็กผู้ชายที่บันทึกจริง** โปรแกรมเลือกเสียงอังกฤษผู้ชายเมื่อเครื่องมีและปรับ pitch เป็น 1.35 หากไม่มีจะใช้เสียงอังกฤษที่หาได้ เสียงจึงแตกต่างตามเครื่อง และบางอุปกรณ์อาจไม่มีเสียงอังกฤษหรืออาจต้องต่ออินเทอร์เน็ตเพื่อพูด

ประโยคตัวอย่าง: “Hello, little artist! Let's paint something wonderful!”, “Great job! Your picture is saved!”, “Wow! Try this texture!” รวมทั้งชื่อสีและเครื่องมือ

หากต้องการเสียงเด็กผู้ชายที่เหมือนกันทุกเครื่อง ขั้นตอนที่ยังเหลือคือจัดหาไฟล์เสียงอังกฤษที่ได้รับอนุญาตให้ใช้งาน แล้วเปลี่ยนฟังก์ชัน `say` ให้เล่นไฟล์เหล่านั้น ไม่ได้รวมไฟล์เสียงเด็กจริงในชุดนี้

## นำขึ้น GitHub Pages

1. แตก ZIP แล้วนำไฟล์ทั้งหมดในชุดไปวางที่ระดับแรกของ repository โดยให้ `index.html` อยู่ระดับแรก ไม่ซ้อนในโฟลเดอร์อื่น
2. ไปที่ Settings → Pages → Build and deployment → Source: Deploy from a branch
3. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้ว Save
4. เมื่อ GitHub เผยแพร่เสร็จ เปิดลิงก์ที่หน้า Pages แสดง

ไม่ต้องติดตั้ง npm หรือใส่ API key ทุกพาธเป็นพาธสัมพัทธ์ รองรับ repository subpath และมี service worker สำหรับเปิดแอปออฟไลน์หลังโหลดครั้งแรกสำเร็จ ส่วนเสียงพูดออฟไลน์ขึ้นกับอุปกรณ์

อ้างอิง: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

ชุดนี้ยังไม่ได้อัปโหลดไปยังบัญชี GitHub ของคุณ

## การตรวจสอบ

ทดสอบด้วย Chrome อัตโนมัติ: เลือกสีและลาย, เปลี่ยนเป็นลูกกลิ้ง, เติมลาย, ย้อนกลับ/ทำซ้ำ, วาด, บันทึกใน IndexedDB, เปิดหน้าตัวอย่าง, ขนาดจอ 1366×900 / 390×844 / 844×390 และโหลดแอปแบบออฟไลน์ ไม่พบ JavaScript error ในการทดสอบดังกล่าว

ยังไม่ได้ฟังเสียงบนอุปกรณ์จริงหรือทดสอบ Safari/iPad จริง

เมื่อแก้ไฟล์ในอนาคต ให้เปลี่ยนชื่อ CACHE ใน `sw.js` เพื่ออัปเดตชุดออฟไลน์
